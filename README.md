# SIH26145-AI-Based-Detection-of-Cyber-Threats-in-Unidirectional-IP-Traffic
Objective: Build an AI-based system that monitors unidirectional IP traffic, extracts network-flow features, detects abnormal behavior, classifies potential cyber threats such as DoS/DDoS and Port Scanning, assigns a risk/confidence score, and displays the results through a real-time dashboard
